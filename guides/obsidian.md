# Notes app: Obsidian (recommended upgrade)

[Obsidian](https://obsidian.md) is free and stores notes as plain Markdown files, which is what Claude writes natively: diagrams (Mermaid), proper maths (LaTeX), linked notes and real spaced-repetition flashcards. It pairs best with the [Cowork route](claude-cowork.md), where Claude writes straight into the vault.

## Set up on the laptop

1. Install Obsidian. Copy `starter-folders/` from this repo to where you want your vault, rename it (e.g. `Year 2`), and copy `kit/` into it as `_system/`.
2. Obsidian › **Open folder as vault** › that folder.
3. In `_system/MY-SETUP.md` set `Notes app: Obsidian`.
4. Optional: Settings › Community plugins › install **Spaced Repetition**, and set `Flashcards go to: Obsidian Spaced Repetition`.

## Where to keep the vault

| Option | Laptop | iPad | Notes |
|---|---|---|---|
| **OneDrive (UoN)** | ✅ | ❌ | Fine on the laptop. Obsidian on iPad can't open a vault in OneDrive. Easiest if you only use Obsidian on the laptop. |
| **iCloud Drive** | ✅ (Windows needs iCloud for Windows) | ✅ | The free way to get the vault on iPad. |
| **Obsidian Sync** | ✅ | ✅ | Paid, most reliable across devices. |

If you want the vault on your iPad, put it in iCloud Drive or use Obsidian Sync. You can still keep the lecture files in OneDrive. With Cowork, give Claude access to both folders.

## On iPad

- Revising: notes, diagrams and flashcards all work in Obsidian on iPad.
- Being taught: use a [Claude Project](claude-projects.md); Claude hands notes back as Markdown code blocks to paste into Obsidian.

## Don't publish your vault

If you put your vault on GitHub, lecture slides and transcripts are UoN's copyrighted material. Keep the repo private or leave them out.
