# Other notes apps

Set `Notes app:` in `MY-SETUP.md` and Claude changes how it formats what it hands back. The teaching is the same.

| App | Set `Notes app:` to | What you get |
|---|---|---|
| **Notion** | `Notion` | Markdown code blocks to paste; Notion renders headings, tables, Mermaid code blocks and `$$` equations. Flashcards as toggle lists. Free with a student account. Not stored in OneDrive. |
| **Any Markdown app** (Logseq, Typora, VS Code, iA Writer, Bear…) | `Other Markdown app` | Same as Obsidian but plain links instead of `[[wikilinks]]`. Claude warns if diagrams might not render. If the files sit in OneDrive, the Cowork route can write them directly. |
| **Goodnotes / Notability** (handwriting on iPad) | `Other: Goodnotes` | Claude asks once what you can paste; usually plain formatted text. Diagrams as outlines or screenshots. |
| **Word** | `Other: Word` | Formatted text to paste; maths via Insert › Equation (accepts LaTeX). |

Whatever app you choose, keep the **working files** (`_module.md`, `PROGRESS.md`, Packs, Tutorial Breakdowns) as `.md` files in your Project or OneDrive. They're for Claude, not you, and they're what let it pick up where you left off.
