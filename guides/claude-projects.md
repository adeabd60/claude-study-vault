# Claude route: Projects (default)

Works on laptop (claude.ai or the Claude app), iPad and phone. One Project per module. Claude can read what you put in the Project but can't save files, so at the end of each session it hands back what changed and you paste it in.

> Whether Projects are on the free plan, and how many you get, has changed over time. If you can't create one, use [free chat](claude-free-chat.md) instead.

## Set up a module (once, ~5 minutes)

1. In Claude, open **Projects** › **Create project**. Name it after the module, e.g. `EXAMPLE101 Example Module`.
2. **Project instructions** — paste:

   > Follow TEACHING-METHOD.md and MY-SETUP.md in this project's files for every chat. My Claude route is Projects.

3. **Project files** — upload:
   - `kit/TEACHING-METHOD.md`
   - your filled-in `kit/MY-SETUP.md`
   - everything in `kit/templates/`
4. Start a chat in the Project and say `set up new module EXAMPLE101 Example Module in Term 1`. Claude asks a few questions, then gives you `_module.md` and `PROGRESS.md` (upload both to the Project) and a Home page for your notes app.

## Each week

1. Save the week's lecture files in OneDrive (`Uni/Year 2/Term 1/EXAMPLE101 Example Module/Week 1/`) as usual.
2. New chat in the Project. Attach the week's slides, transcripts and tutorial sheet (on iPad: attach › Files › OneDrive), and say `prep week 1 of EXAMPLE101`.
3. Claude gives back the **Pack** and **Tutorial Breakdown** (upload to the Project — they're what later sessions build on) and the week's **Notes** (paste into your notes app).
4. `teach me week 1, I have 45 minutes` … `end session`.
5. At the end, Claude gives back the new `PROGRESS.md` entry and updated Pack/Tutorial Breakdown (replace them in the Project), plus the session note, flashcards and to-do changes for your notes app.

## Tips

- **One chat per session.** Long chats get slow and hit limits sooner.
- **Project files fill up.** Once a few weeks are done, remove old weeks' lecture files from the Project but keep every Pack and `PROGRESS.md`.
- **Replacing a file**: delete the old one in the Project and upload the new one, or add text content with the same name.
- If Claude can offer a downloadable file instead of a code block, take it: it's easier to upload.
